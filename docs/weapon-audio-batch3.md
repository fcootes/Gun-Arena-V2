# Weapon audio: final supplied batch

The nine supplied WAVs in `src/assets/audio/weapons/batch3` complete SMG firing, plasma firing/reloading and railgun charge/shot audio. Static asset URLs package them through Vite, including subpath deployments. The adjacent manifest preserves editing cuts, PCM sample counts and baseline timings; the uploaded README was read as editing guidance and is not copied as a current integration report.

SMG firing starts with one single report and transitions to one sustained 1.728 s loop (24 reports at the existing 72 ms cadence). The last round uses an individual report and stops the loop. Plasma similarly uses a shortened 0.165 s tap and a 1.100 s loop (20 pulses at 55 ms spacing), with a final individual pulse when reaching the heat cap. Bot shot callbacks use single reports. The plasma weapon retains its existing beam visuals, raycasts, damage, heat rules and reload animations; this batch does not implement the planned projectile-rifle conversion.

Plasma manual cooling plays the supplied 2.200 s hiss fitted to the active class-adjusted reload total. Its existing battery-insert animation also plays one chamber input near the end of the insert phase, at baseline 1.585 s. That cue follows reload simulation time, so pause freezes it and switching/cancellation clears it. A frame reaching the cue late seeks the corresponding clip offset; a frame skipping the entire cue does not play a stale insert. Automatic overheat uses the supplied 2.200 s vent/replacement composite, which already includes the chamber input, so it never layers the separate hiss or input on top. Because the current beam weapon does not decrement its ammo field, full heat/overheat selects this composite rather than an ammo-zero test.

Railgun charge starts once and follows the existing 1.200 s charge timer. Its initial cursor matches progress already elapsed on the first update. Early release immediately stops charge; the shot transition stops charge and starts the supplied 2.400 s report once. The report's natural decay may overlap the existing reload. Synthetic charge and blast calls are removed from gameplay. No dedicated railgun reload recording was supplied; that existing reload sound path is retained.

All integrated assets pause/resume with their position and playback speed intact. Release stops firing loops and railgun charge. Reload, switching, death, match reset, field refill and teardown stop their applicable sounds and pending cues. Previous audio batches remain integrated.

Validation: TypeScript, production build, audio tests, actual reload-handler dispatch, tactical reload/animation tests, weapon tests, batch-one lifecycle tests and runtime checks. Audio tests inspect all 40 bundled PCM assets and exercise the new loop, plasma reload and railgun cancellation behavior alongside earlier batches. An in-game listening check remains pending.
